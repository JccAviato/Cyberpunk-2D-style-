# Cyber Odyssey — Pygame Prototype

## Quick start
1. Install Python 3.10+ and Pygame:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python main.py
   ```

## Controls
- Move: A/D or Left/Right
- Jump: W/Up/Space  (double-jump unlockable)
- Dash: Left Shift
- Attack: J or Z or Left Ctrl
- Interact / Use: E
- Quick Heal: H (consumes NanoGels)
- Pause: P
- Quest Log: Q
- Save: F5  |  Load: F9
- Restart after death/end: R  | Quit: Esc

## Highlights
- 6 connected areas via doors
- NPCs, lore, and branching choice with multiple endings
- Enemies: walkers, flyers, turrets (projectiles), and a boss
- Puzzle elements: switches + gates
- Inventory (NanoGels, micro-core); quick-heal; drops
- Unlockable double-jump; dash with cooldown
- Save/Load system (JSON)

This is a code‑only prototype with rectangles and simple effects to keep it portable and error‑free.
